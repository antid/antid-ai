# antid.co — Portfolio

AI Product Designer & Builder portfolio. Built with React + Vite.

Design that ships.

## Sections

- **Hero** — "Design that ships" with scroll indicator
- **Skills Marquee** — Rotating skills ticker
- **Work** — Selected projects incl. Design-Aware Code Review, Decision Partner, Enterprise Observability
- **About** — Background, experience, stats
- **Contact** — Reach out at hello@antid.co

## Running locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
